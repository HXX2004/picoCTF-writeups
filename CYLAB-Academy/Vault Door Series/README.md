# 從vault-door-1學到甚麼
1. **原始碼分析：** 密碼驗證邏輯可能直接透露正確密碼，不一定需要破解演算法。
2. **Java 字串操作：** `substring()` 可以擷取字串，`charAt()` 可以讀取指定索引的字元。
3. **索引從 0 開始：** `charAt(0)` 代表第一個字元，不能將索引當成一般從 1 開始的排列位置。
4. **Python 自動化：** 使用正規表達式擷取索引與字元，再依索引重新排列，可以減少人工整理時的錯誤。
5. **可重複使用的技巧：** 遇到類似的 `charAt(index) == '字元'` 條件，可以利用程式自動還原字串。
