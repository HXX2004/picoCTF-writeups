## 六、學習重點

1. **頻率分析：** 利用英文常見字母的出現頻率，推測密文中的字母對應。
2. **單字母替換密碼：** 每個密文字母固定對應一個明文字母，可以透過反向映射還原。
3. **善用線上工具：** 線上解密工具可以協助分析密文，但仍需理解替換規則，才能判斷結果是否正確。
4. **交叉驗證：** 如果題目已提供字母表，可以直接利用字母對照驗證解密結果，不必完全依賴工具的自動分析。
5. **人工驗證：** 自動解密工具的結果不一定完全正確，需要根據文章語意修正錯誤的字母映射。
6. **替換表的一致性：** 同一個密文字母在整篇文章中應固定對應同一個明文字母，因此修改映射後，要再次檢查整段文章與旗子。
